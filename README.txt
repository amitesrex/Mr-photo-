MR Scanner Bridge — कंप्यूटर के स्कैनर से सीधे MR Photo में स्कैन
==================================================================

ब्राउज़र / PWA सीधे स्कैनर से बात नहीं कर सकता (सुरक्षा के कारण)। इसलिए कंप्यूटर पर
यह छोटा प्रोग्राम चलता है, जो Windows के WIA (वही जो "Windows Scan" ऐप इस्तेमाल करती है)
से स्कैनर चलाकर फोटो ऐप को दे देता है। कुछ इंस्टॉल नहीं करना — PowerShell Windows में पहले से है।

कैसे चलाएं (Windows 10 / 11)
-----------------------------
1) प्रिंटर / स्कैनर को कंप्यूटर से जोड़ें, चालू करें (Windows में उसका ड्राइवर लगा हो;
   "Windows Scan" ऐप से एक बार स्कैन चल जाए तो यह भी चलेगा)।
2) Start-Scanner.bat पर डबल क्लिक करें। काली विंडो में एक 6 अंकों का "Pairing CODE" दिखेगा।
   यह विंडो खुली रहनी चाहिए।
3) MR Photo में:  फोटो टैब -> "स्कैनर / प्रिंटर से स्कैन" -> पहली बार वही कोड डालें -> जोड़ें।
4) स्कैनर चुनें, DPI / रंग / एरिया (A4, A5, 4x6, पूरा बेड) चुनें -> "स्कैन शुरू करें"।
   स्कैन होते ही फोटो क्रॉप स्टूडियो में खुल जाती है।

कोड सिर्फ एक बार डालना होता है (token.txt में सेव रहता है)। इसी कोड से कोई दूसरी वेबसाइट
आपके स्कैनर को नहीं चला सकती। कोड बदलना हो तो token.txt डिलीट करके दोबारा चलाएं।

अगर कनेक्ट न हो
----------------
- Chrome / Edge पूछे कि "लोकल नेटवर्क / डिवाइस तक पहुंच दें?" -> Allow दबाएं।
- काली विंडो में लाल ERROR दिखे तो वही लाइन देखें (अक्सर "Scanner nahi mila" = ड्राइवर / केबल / WiFi)।
- WiFi प्रिंटर हो तो कंप्यूटर में Settings > Printers & scanners में वह "Scan" के लिए दिखे।
- किसी स्कैनर में चुना हुआ एरिया / DPI नहीं चलता तो "पूरा बेड" चुनें, फिर क्रॉप स्टूडियो में काटें।
- Port 8765 पहले से किसी और प्रोग्राम के पास हो तो वह बंद करें।
- Safari / iPhone में localhost कॉल ब्लॉक होती है — वहां नीचे वाला "फोन" तरीका इस्तेमाल करें।

टेस्ट मोड (स्कैनर के बिना जांचने के लिए)
-------------------------------------------
powershell -ExecutionPolicy Bypass -File MR-Scanner-Bridge.ps1 -MockImage C:\path\kisi-photo.jpg
ऐप में "टेस्ट मोड" दिखेगा और स्कैन की जगह वह फोटो आएगी।

फोन से (Android) — Bridge की ज़रूरत नहीं
-----------------------------------------
प्रिंटर की अपनी ऐप (HP Smart / Canon PRINT / Epson Smart Panel) से स्कैन करें -> स्कैन पर
Share -> "MR Photo" चुनें। (MR Photo Android Chrome में Install की हुई होनी चाहिए।)
iPhone में PWA "Share to" नहीं लेता — स्कैन गैलरी में सेव करके ऐप में "गैलरी" से चुनें।
